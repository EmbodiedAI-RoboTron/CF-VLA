# Contributing

## Workflow
1. Create a feature branch.
2. Keep commits focused and reviewable.
3. Run local checks before opening a PR.

## Code Guidelines
- Prefer clear, minimal, and testable changes.
- Keep backward compatibility for `pi0_2stg_pytorch` configs.
- Do not commit datasets, checkpoints, or secret material.

## PR Checklist
- [ ] No hardcoded credentials or private paths.
- [ ] Documentation updated when behavior changes.
- [ ] Smoke checks performed for training/serving paths.
